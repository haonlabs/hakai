# Brief 05: e2e (S)

## Tujuan
Satu tes end-to-end. (README ditulis Claude sendiri: dokumen tidak didelegasikan; jangan buat atau ubah `README.md`.)

## Aturan umum
- E2E memakai vault fixture di temp dir dan `AUDIT_FILE` temp; **tidak boleh menyentuh vault asli**. Commit tanpa trailer agent. Laporkan hasil tes.

## Yang dikerjakan
1. Playwright (dev dependency), satu skenario: jalankan server dengan `VAULT_ROOT` fixture → Keep satu catatan (item tersembunyi dari filter default) → Delete satu catatan lewat dialog (file hilang dari fixture, baris `index.md` bersih, item hilang dari daftar) → Delete massal dengan konfirmasi angka.
2. Script `test:e2e` di `package.json`; `playwright.config.ts` menjalankan server dev/preview dengan env fixture (`VAULT_ROOT`, `AUDIT_FILE` ke temp dir yang dibuat di global setup).

## Kriteria selesai
`npm run test:e2e` lulus; `npm test` tetap lulus.
