# Brief 04: UI Svelte (M)

## Tujuan
Mengimplementasikan layar Hakai sesuai desain Figma (screenshot di `docs/figma/`, token di `briefs/00-index.md`). Berjalan paralel dengan brief 03; sebelum 03 selesai, tes UI memakai data dummy lewat props.

## Aturan umum
- Hanya source code (komponen, CSS, test). Jangan ubah `docs/`, jangan ubah desain; kalau ada yang tidak masuk akal di layar, laporkan, jangan improvisasi. Tema gelap/terang lewat CSS variables + `prefers-color-scheme`. Verdict selalu berupa teks, tidak hanya warna.
- Commit tanpa trailer agent. Laporkan: file + hasil `npm run build` dan `npm run check`.

## Boleh disentuh
`src/routes/+page.svelte`, `src/routes/+layout.svelte`, `src/app.css`, `src/lib/components/*.svelte`. Jangan ubah `+page.server.ts` atau `src/lib/*.ts`.

## Layar (lihat screenshot)
1. **Review (01/02)**: sidebar 240px (brand 破 Hakai, filter Verdict radio + hitungan, Sumber checkbox, toggle "Sembunyikan ditinjau", daftar pintasan); topbar (judul, meta audit, search dengan kbd `/`); banner kuning bila `audit.stale || audit.unaudited > 0`; toolbar (jumlah + tombol massal nonaktif sampai ada centang); tabel (checkbox, nama mono, badge verdict, sumber, diubah, alasan terpotong); panel detail di bawah tabel (nama, badge, tombol Buka di Obsidian / Keep `e` / Delete `d`, meta, kolom kiri alasan + backlinks, kolom kanan preview Markdown).
2. **Dialog Delete (03)**: `<dialog>` native; path, peringatan kuning bila `brokenLinksIn.length > 0` (diambil dari `backlinks` detail), teks "Tidak bisa dibatalkan", Batal (fokus awal) dan "Hapus permanen" (merah). `Esc` = Batal.
3. **Dialog Delete massal (04)**: daftar path, input "Ketik N untuk mengonfirmasi"; tombol hapus nonaktif sampai input = jumlah item.
4. **Empty state (05)**: tampil bila tidak ada item setelah filter dan `counts.unreviewed === 0`.
- Pemilihan baris memakai query string `?note=<path>` (data `detail`/`detailError` dari `load` di `/`, lihat kontrak), supaya refresh mempertahankan pilihan. Tidak ada route `/note/...`. Pertahankan query filter lain saat berpindah baris (`goto` dengan `keepFocus`, `noScroll`).
- Pintasan: `j`/`k` pindah baris, `x` centang, `e` Keep, `d` buka dialog Delete, `/` fokus search; abaikan saat fokus di input. Setelah Keep/Delete, pindah ke baris berikutnya di filter yang sama.
- Preview Markdown: `marked` + `isomorphic-dompurify`; wikilink `[[x]]` dirender sebagai chip non-klik.
- Aksi lewat `use:enhance` ke form actions; error (`fail`) tampil sebagai toast sederhana.

## Kriteria selesai
`npm run build` dan `npm run check` lulus; layar cocok dengan screenshot pada lebar 1440; tampilan layak di lebar ≥ 1024.
